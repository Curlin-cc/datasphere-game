# Datasphere Game

A browser-based learning game that simulates SAP Datasphere. As a new data architect at the fictional
utility *Stadtwerke Rheinau*, you build a complete Datasphere landscape step by step: spaces, roles,
layers, SQL views, semantics, analytic models, data access controls and task chains.

You do every step yourself. The game only gives hints and reviews your work.

Not affiliated with SAP. This is an independent learning project.
